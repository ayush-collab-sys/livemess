# Applying the realistic theme

Keep your existing stylesheet and add this line after it in your HTML `<head>`:

```html
<link rel="stylesheet" href="realistic-theme.css">
```

The theme changes the white-and-flat look into a warmer, production-style dashboard:

- deep navy navigation with a green active state
- off-white background with subtle radial lighting
- layered card shadows and hover lift
- richer green gradients for buttons, charts, and progress bars
- clearer form focus states and more polished badges
- responsive spacing retained for mobile layouts

Because it is an override layer, you can remove the link at any time to return to your original design. To change the whole palette, edit the color variables at the top of `realistic-theme.css`.
